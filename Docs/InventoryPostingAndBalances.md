# Проведение, удаление и остатки материалов

## Запись и проведение

При записи документа ТМЗ шапка, строки, проводки и отметка о проведении фиксируются одной транзакцией PostgreSQL. При корректировке старые проводки заменяются в той же транзакции. Ошибка в любой строке отменяет всю запись. Если это корректировка, в базе сохраняется предыдущая редакция документа и её проводки.

Было в карточке:

```csharp
await metadata.UpdateDynamicRecordAsync(_document.Id, targetId.Value, data, lines);
if (!await PostSavedDocumentAsync())
    return;
```

Теперь проведение выполняется в сервисе записи до фиксации транзакции:

```csharp
if (inventoryLines != null)
    await ReplaceInventoryPostingsAsync(metadata, recordId, inventoryLines);

if (transaction != null)
    await transaction.CommitAsync();
```

## Пункт 3. Остатки и выбытие

Два представления PostgreSQL рассчитывают движения и остатки по проведённым первичным документам. Поступление добавляет количество на участок и материально ответственное лицо получателя. Выбытие вычитает количество со стороны отправителя. Перемещение формирует расход у отправителя и приход у получателя.

Остаток группируется по материалу, участку, материально ответственному лицу и счёту хранения. При проведении выбытия или перемещения суммы количества по одинаковым строкам проверяются вместе. Для записи используется остаток непосредственно перед документом в хронологическом порядке. Окно подбора показывает предварительную доступность на дату документа. Параллельные операции проведения и удаления ТМЗ используют одну транзакционную блокировку PostgreSQL.

Кнопка **«Остатки материалов»** открывает сводку в журнале ТМЗ. Если при подборе материала в выбытии или перемещении выбран участок и материально ответственное лицо отправителя, окно показывает материалы с положительным остатком и количество по счетам.

Сумма в сводке учитывает автоматически рассчитанную себестоимость расхода и перемещения. Порядок пересчёта при изменении задним числом приведён в [отдельном документе](InventoryCostRecalculation.md). Импорт начальных остатков и распределение дополнительных расходов остаются отдельными задачами. Исторические поступления с пустым участком или материально ответственным лицом видны в общей сводке, но не считаются доступными на конкретном участке.

## Пункт 4. Документ всегда проведён

Самостоятельной отмены проведения для ТМЗ нет. Корректировка выполняется через редактирование и заменяет документ вместе с его проводками. Для старых непроведённых записей журнал сохраняет команду **«Провести»**. Новая запись с ошибкой проведения не оставляет первичный документ без проводок.

При удалении проводки очищаются из `doc_postings` по прямой ссылке. Шапка и строки удаляются в той же транзакции. Записи с таким же номером у другого документа не затрагиваются.

```sql
DELETE FROM doc_postings
WHERE document_table = @table AND document_id = @id;
```

# Исправление предпросмотра печатных форм

Документ описывает исправление предпросмотра: почему документ открывался
в браузере и что сделано, чтобы он показывался в окне программы.

Исправление выполнено в версии **1.1.236**.

---

## 1. Что было не так

При предпросмотре печатной формы происходило следующее:

1. открывалось окно **«Предпросмотр печатной формы»**;
2. в нём появлялась надпись «PDF сформирован»;
3. **запускался браузер** и показывал PDF;
4. в окне программы при этом ничего не отображалось.

Пользователь видел два окна вместо одного, причём **полезное содержимое
было в чужом окне** — в браузере.

---

## 2. Причина

Причин было **две**, и они лежали в разных местах.

### Причина первая: окно предпросмотра не умело показывать PDF

Файл `Views/PdfPreviewWindow.xaml` не содержал средства просмотра —
только надпись и кнопку «Открыть PDF».

В `Views/PdfPreviewWindow.xaml.cs` было так:

```csharp
private void OnLoaded(object sender, RoutedEventArgs e)
{
    EnsureTempPdfFile();

    Title = $"Предпросмотр - {Path.GetFileName(_tempFilePath)}";
    PreviewStatusText.Text = "PDF сформирован. Открываю документ во внешнем просмотрщике...";
    OpenPdfExternally(showError: false);   // ← запуск внешней программы
}

private void OpenPdfExternally(bool showError)
{
    Process.Start(new ProcessStartInfo
    {
        FileName = _tempFilePath,
        UseShellExecute = true          // ← система сама выбирает программу
    });
}
```

**Окно открывалось и сразу запускало внешнюю программу.** Для PDF системой
назначен браузер — отсюда он и появлялся.

### Причина вторая: рабочий режим вообще не использовал окно

В `Views/AccountingReportsView.xaml.cs` документ писался на диск
и открывался внешней программой:

```csharp
var outputPath = BuildTemporaryReportPath($"{_currentReport.Name}_PROGRAM", "pdf");
File.WriteAllBytes(outputPath, pdfBytes);
OpenGeneratedFile(outputPath);      // ← Process.Start
```

```csharp
private static void OpenGeneratedFile(string filePath)
{
    System.Diagnostics.Process.Start(new System.Diagnostics.ProcessStartInfo
    {
        FileName = filePath,
        UseShellExecute = true
    });
}
```

**Это был формат по умолчанию** — «Программный PDF», поэтому поведение
с браузером встречалось постоянно.

### Итог по причинам

| Место | Что делало не так |
| --- | --- |
`PdfPreviewWindow` | Не показывало PDF, запускало внешнюю программу |
`AccountingReportsView` | Писало файл и запускало внешнюю программу |
`ReportDesignerWindow` | То же для предпросмотра макета |

---

## 3. Что сделано

### Средство просмотра PDF внутри окна

Использован **WebView2** — встроенный просмотрщик на движке Edge.
Он умеет показывать PDF и имеет собственную печать.

**Пакет добавлен в проект:**

```xml
<PackageReference Include="Microsoft.Web.WebView2" Version="1.0.2903.40" />
```

**Просмотрщик встроен в окно** (`Views/PdfPreviewWindow.xaml`):

```xml
<wv2:WebView2 x:Name="PdfView" Visibility="Collapsed"/>
```

### Загрузка документа

```csharp
var environment = await CoreWebView2Environment.CreateAsync(
    browserExecutableFolder: null,
    userDataFolder: userDataFolder);

await PdfView.EnsureCoreWebView2Async(environment);

// Доступ открывается только к каталогу с документом.
PdfView.CoreWebView2.SetVirtualHostNameToFolderMapping(
    "bis-preview",
    Path.GetDirectoryName(_tempFilePath)!,
    CoreWebView2HostResourceAccessKind.DenyCors);

PdfView.CoreWebView2.Navigate(
    $"https://bis-preview/{Uri.EscapeDataString(Path.GetFileName(_tempFilePath))}");
```

**Внешняя программа не запускается.** Документ показывается в окне программы.

### Печать

Печатает **встроенный просмотрщик** — диалог печати открывается поверх окна:

```csharp
private void OnPrintClick(object sender, RoutedEventArgs e)
{
    if (_viewerReady && PdfView.CoreWebView2 != null)
    {
        // Системный диалог печати поверх окна.
        PdfView.CoreWebView2.ShowPrintUI();
        return;
    }

    // Запасной путь: печатает программа, назначенная для PDF.
    Process.Start(new ProcessStartInfo
    {
        FileName = _tempFilePath,
        UseShellExecute = true,
        Verb = "print"
    });
}
```

**Проверено, что метод есть в библиотеке:**

```
M:Microsoft.Web.WebView2.Core.CoreWebView2.ShowPrintUI
M:Microsoft.Web.WebView2.Core.CoreWebView2.ShowPrintUI(CoreWebView2PrintDialogKind)
```

### Новое окно

```
┌──────────────────────────────────────────────────────────┐
│ 📄 Журнал счет-фактур                                    │
├──────────────────────────────────────────────────────────┤
│                                                          │
│        [ PDF отображается здесь, с прокруткой ]          │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ Документ открыт.                                         │
│        🖨 Печать   💾 Сохранить PDF   🌐 Внешняя   ❌ Закрыть│
└──────────────────────────────────────────────────────────┘
```

| Кнопка | Что делает |
| --- | --- |
**🖨 Печать** | **Системный диалог печати прямо из окна** |
**💾 Сохранить PDF** | Сохраняет документ на диск под понятным именем |
**🌐 Внешняя программа** | Открывает документ назначенной для PDF программой |
**❌ Закрыть** | Закрывает окно |

### Имя документа в заголовке

Окно теперь принимает имя документа:

```csharp
public PdfPreviewWindow(byte[] pdfData, string? documentName = null)
{
    _documentName = string.IsNullOrWhiteSpace(documentName) ? "Документ" : documentName.Trim();
    Title = $"Предпросмотр — {_documentName}";
    TitleText.Text = _documentName;
}
```

**В заголовке** — название отчёта, а не имя временного файла.
**При сохранении** предлагается понятное имя: `Журнал счет-фактур_20261012_1430.pdf`.

### Запасной вариант

Если встроенный просмотрщик недоступен, окно не падает:

```csharp
private void ShowFallback(string message)
{
    _viewerReady = false;
    PdfView.Visibility = Visibility.Collapsed;
    PlaceholderPanel.Visibility = Visibility.Visible;
    FallbackOpenButton.Visibility = Visibility.Visible;
    PreviewStatusText.Text = message;
    StatusText.Text = "Просмотр в окне недоступен.";
}
```

Пользователь видит объяснение и кнопку **«Открыть во внешней программе»**.
Печать в этом случае идёт через системную.

### Уборка временного файла

Просмотрщик держит файл открытым, поэтому сначала его отключают от документа:

```csharp
protected override void OnClosed(EventArgs e)
{
    try
    {
        if (PdfView?.CoreWebView2 != null)
        {
            PdfView.CoreWebView2.Navigate("about:blank");
            PdfView.Dispose();
        }
    }
    catch { }

    base.OnClosed(e);
    TryDeleteTempFile();   // три попытки с паузой
}
```

## 4. Что исправлено по местам

**Пять путей формирования PDF** теперь показывают документ в окне.

| Что | Где | Было | Стало |
| --- | --- | --- | --- |
**Программный PDF** | `AccountingReportsView:2303` | файл → браузер | **окно** |
**Нативный PDF** | `AccountingReportsView:2360` | файл → браузер | **окно** |
**FRX PDF** | `AccountingReportsView:2420` | файл → браузер | **окно** |
**Предпросмотр в конструкторе** | `ReportDesignerWindow:950` | файл → внешняя | **окно** |
**Предпросмотр в конфигураторе** | `ConfiguratorWindow:3104` | окно без имени | **окно с именем** |

### Общий метод в рабочем режиме

Добавлен один метод вместо трёх копий:

```csharp
/// <summary>
/// Показывает сформированный PDF в окне предпросмотра.
///
/// Документ не пишется на диск и не открывается внешней программой:
/// просмотр и печать выполняются в самом окне.
/// </summary>
private void ShowPdfPreview(byte[] pdfBytes, string documentName)
{
    var previewWindow = new PdfPreviewWindow(pdfBytes, documentName)
    {
        Owner = Window.GetWindow(this)
    };
    previewWindow.ShowDialog();
}
```

Три места вместо записи файла вызывают его:

```csharp
ShowPdfPreview(pdfBytes, $"{_currentReport.Name} (программный)");
ShowPdfPreview(await pdfTask, $"{_currentReport.Name} (нативный)");
ShowPdfPreview(await pdfTask, $"{_currentReport.Name} (FRX)");
```

**Файл на диск для предпросмотра больше не пишется вообще.**

### Предпросмотр макета в конструкторе

```csharp
var printFormParameters = await _reportService.ResolveParametersForPreviewAsync(report);
var pdfBytes = _printFormService.ExportTemplatePreview(report, printFormParameters);

// Показываем документ прямо в окне: внешняя программа не запускается.
var previewWindow = new PdfPreviewWindow(pdfBytes, report.Name) { Owner = this };
previewWindow.ShowDialog();
```

## 5. Что оставлено без изменений

**Excel открывается внешней программой — и должен.** Excel это редактор,
его и нужно открывать.

| Место | Почему правильно |
| --- | --- |
Экспорт отчёта в Excel | Пользователь работает с таблицей |
Экспорт ClosedXML в Excel | То же |
Сохранение PDF на диск | Пользователь выбирает файл сам |

Поэтому метод `OpenGeneratedFile` **остался** — им пользуется экспорт в Excel:

```csharp
// Осталось для Excel: там нужен внешний редактор.
private static void OpenGeneratedFile(string filePath)
{
    System.Diagnostics.Process.Start(new ProcessStartInfo
    {
        FileName = filePath,
        UseShellExecute = true
    });
}
```

## 7. Требования к машине

Встроенный просмотрщик — это **WebView2 Runtime** от Microsoft.

| Что | Значение |
| --- | --- |
Пакет NuGet | `Microsoft.Web.WebView2 1.0.2903.40` |
Где искать Runtime | `C:\Program Files (x86)\Microsoft\EdgeWebView\Application` |
Версия на машине разработки | **154.0.4258.62** |
Есть ли на Windows 10/11 | **Почти всегда** — ставится с Edge |

**Библиотеки копируются в сборку автоматически:**

```
bin\Debug\net8.0-windows\
    Microsoft.Web.WebView2.Core.dll      590 KB
    Microsoft.Web.WebView2.Wpf.dll        82 KB
    Microsoft.Web.WebView2.WinForms.dll   38 KB
```

**Если Runtime нет** — окно покажет объяснение и кнопку для внешней программы.
Печать при этом работает через систему.

## 8. Как проверить

### Проверка 1. Программный PDF

1. Открыть **Бухгалтерская отчётность**.
2. Выбрать отчёт, например «Акт сверки (ClosedXML)».
3. Нажать **Сформировать**.
4. Формат вывода: **Программный PDF**.
5. Нажать **Открыть**.

| Ожидание | Результат |
| --- | --- |
Открылось **одно** окно | окно предпросмотра |
Внутри виден документ | да |
**Браузер не запустился** | да |
В заголовке — имя отчёта | да |

### Проверка 2. Печать

1. В окне предпросмотра нажать **🖨 Печать**.
2. Ожидание: **системный диалог печати** поверх окна.

### Проверка 3. Сохранение

1. Нажать **💾 Сохранить PDF**.
2. Ожидание: диалог сохранения с именем вида
   `Акт сверки_20261012_1430.pdf`.

### Проверка 4. Предпросмотр в конструкторе

1. Конфигуратор → Отчеты → открыть отчёт.
2. Вкладка **📊 ClosedXML макет**.
3. Нажать **📄 Предпросмотр PDF**.

| Ожидание | Результат |
| --- | --- |
Документ в окне | да |
Браузер не запустился | да |

### Проверка 5. Экспорт в Excel не сломан

1. Формат вывода: **Программный Excel**.
2. Нажать **Открыть**.
3. Ожидание: **открывается Excel** — как и раньше.

# Отключение FRX

FRX отключён на время перехода на ClosedXML. Код FRX **сохранён полностью** —
возврат выполняется одной строкой.

---

## Как включить и выключить

Единственная точка управления — файл `Services/ReportingFeatures.cs`:

```csharp
/// <summary>
/// Формирование отчётов по макетам FoxPro FRX.
/// Отключено на время перехода на ClosedXML.
/// </summary>
public const bool FrxEnabled = false;
```

| Значение | Что происходит |
| --- | --- |
| `false` | FRX скрыт в интерфейсе и не может сработать |
| `true` | FRX возвращается полностью, без других правок |

После изменения — **пересобрать проект**. Других действий не требуется.

---

## Что отключается при `FrxEnabled = false`

### 1. Списки выбора вариантов

| Место | Было | Стало |
| --- | --- | --- |
| Акт сверки | Стандартный + 18 FRX-вариантов | **Только «Акт сверки»** |
| Оборотная ведомость | Программная + FRX-варианты | **Только «Программная ОСВ»** |

Список становится неактивным (`IsEnabled = false`), потому что выбор
из одного пункта не имеет смысла.

Загрузка вариантов из базы **пропускается целиком** — лишних запросов нет.

**Файл:** `Views/AccountingReportsView.xaml.cs`
**Методы:** `LoadReconciliationReportVariantsAsync`, `LoadTrialBalanceReportVariantsAsync`

### 2. Форматы вывода

| Формат | Состояние |
| --- | --- |
| Программный Excel / PDF | работает |
| Нативный Excel / PDF | работает |
| **ClosedXML Excel** | работает |
| **ClosedXML PDF** | работает |
| FRX FoxPro Excel | **скрыт** |
| FRX FoxPro PDF | **скрыт** |

Пункты FRX не удалены из разметки, а помечены `Visibility="Collapsed"` —
чтобы вернуть, достаточно убрать атрибут.

Дополнительно `GetSelectedReportOutputFormat` подменяет формат FRX
на `ClosedXmlExcel`. Это защита на случай, если формат был задан программно:
отчёт всё равно сформируется, а не упадёт с ошибкой.

**Файлы:** `Views/AccountingReportsView.xaml` (разметка),
`Views/AccountingReportsView.xaml.cs` (`GetSelectedReportOutputFormat`)

### 3. Конструктор отчётов

| Элемент | Состояние |
| --- | --- |
| Вкладка «🔗 FRX поля» | скрыта |
| Вкладка «🧱 Нативный макет» | скрыта |
| Поле «FRX-шаблон» и кнопка загрузки | скрыто |
| Тип отчёта «Макет Visual FoxPro FRX» | скрыт из списка |
| Пункт способа макета «FRX — макет FoxPro» | скрыт из списка |
| Вкладка «📊 ClosedXML макет» | **видна** |

Способ макета принудительно переводится в ClosedXML:
`SetLayoutKind` подменяет `FoxProFRX` на `ClosedXml`, поэтому даже
при открытии старого FRX-отчёта конструктор покажет ClosedXML-ветку.

**Файл:** `Views/ReportDesignerWindow.xaml.cs`

| Метод | Роль |
| --- | --- |
| `ApplyLayoutKindVisibility` | Учитывает флаг при расчёте `isFrx` |
| `HideFrxLayoutKindItem` | Скрывает пункт выбора способа макета |
| `SetLayoutKind` | Запрещает установку способа FRX |

### 4. Конфигуратор

| Элемент | Состояние |
| --- | --- |
| Кнопка «📁 Импорт FRX» | скрыта |
| Кнопка «Анализ FoxPro» | скрыта |

Обработчик `OnImportFrxClick` дополнительно проверяет флаг и выходит,
если FRX отключён.

**Файл:** `Views/ConfiguratorWindow.xaml.cs`
**Метод:** `ApplyReportingFeaturesVisibility`

### 5. Защита в службе печати

Даже если FRX-путь будет вызван в обход интерфейса, он не сработает.
В `Services/PrintFormService.cs` добавлен метод:

```csharp
private static void EnsureFrxEnabled()
{
    if (!ReportingFeatures.FrxEnabled)
    {
        throw new InvalidOperationException(
            "Вывод по макетам FoxPro FRX отключён. " +
            "Включите ReportingFeatures.FrxEnabled или выберите формат ClosedXML.");
    }
}
```

Проверка стоит в начале методов:

| Метод | Назначение |
| --- | --- |
| `ExportTemplatePreview` | Предпросмотр макета |
| `ExportReportTemplatePreview` (3 перегрузки) | PDF по макету |
| `ExportReportTemplateExcel` (3 перегрузки) | Excel по макету |

### 6. Признаки наличия FRX-макета

| Файл | Метод |
| --- | --- |
| `Views/AccountingReportsView.xaml.cs` | `HasFoxProTemplate` |
| `Views/ReportPreviewWindow.xaml.cs` | `HasFoxProTemplate` |

Оба возвращают `false` при отключённом FRX. Поэтому предпросмотр отчёта
идёт обычным путём и не пытается строить FRX-разметку.

## Что продолжает работать

| Что | Почему |
| --- | --- |
Отчёты FRX **остались в базе** | Ничего не удалено |
Макеты, парсер, `PrintFormService` | Код цел |
Хранимые привязки полей | Ничего не менялось |
Отчёты ClosedXML | Работают полностью |
Программные и нативные форматы | Не затронуты |
Оборотная ведомость | Программный вариант работает |

**Физически ничего не удалено** — по твоему требованию: оставляем,
пока ClosedXML не станет достойной заменой.

## Созданный файл

`Services/ReportingFeatures.cs` — единая точка управления:

| Член | Назначение |
| --- | --- |
| `FrxEnabled` | Главный переключатель |
| `ClosedXmlEnabled` | Переключатель ClosedXML |
| `IsFrxReport(Report)` | Признак FRX-отчёта |
| `IsFrxFormat(string)` | Признак FRX-формата |

Смысл файла — **один переключатель вместо флагов, разбросанных по коду**.
При возврате FRX не нужно искать места правок.

---

## Порядок возврата FRX

1. Установить `ReportingFeatures.FrxEnabled = true`.
2. Убрать `Visibility="Collapsed"` у двух пунктов формата
   в `Views/AccountingReportsView.xaml`.
3. Пересобрать проект.

Пункт 2 нужен потому, что видимость задана в разметке.
При желании его можно заменить на установку видимости из кода —
тогда останется только первый шаг.

---

## Как проверить, что FRX отключён

| Проверка | Ожидаемый результат |
| --- | --- |
Акт сверки → список вариантов | Один пункт, список неактивен |
Оборотка → список вариантов | Один пункт, список неактивен |
Форматы вывода | Два пункта ClosedXML, пунктов FRX нет |
Конструктор → вкладки | Только «📊 ClosedXML макет» |
Конструктор → способ макета | Выбор способа отсутствует |
Конфигуратор | Кнопки импорта FRX и анализа FoxPro отсутствуют |
Акт сверки → ClosedXML PDF | Формируется, 2 страницы |

# Виды макета: простой и форматный

Документ описывает разделение визуальных макетов на два вида и средства,
добавленные для печатных бланков: многоуровневую шапку, объединение ячеек
по вертикали и поворот текста.

Выполнено в версии **1.1.24x**.

---

## 1. Зачем разделять

Отчёты бывают двух разных природ, и собирать их одним набором средств неудобно.

| Что это | Пример | Что нужно |
| --- | --- | --- |
**Список** | Журнал счет-фактур, реестр, ведомость | Одна строка шапки, ровные колонки |
**Бланк** | Счёт-фактура (СТ-1), накладная | Несколько уровней шапки, объединения, вертикальные подписи графов |

**Бланк нельзя собрать средствами списка:** в нём шапка двух- и трёхуровневая,
подписи графов стоят вертикально, а ячейки объединяются и по горизонтали,
и по вертикали.

Поэтому вид макета задаётся явно — **вкладка «📋 Общие»**.

---

## 2. Вид макета

На вкладке **«📋 Общие»**, в блоке **«Способ макета»**, добавлен выбор:

```
Вид макета:  (•) Простой макет    ( ) Форматный макет
```

| Вид | Для чего | Что доступно |
| --- | --- | --- |
**Простой макет** | Журналы, реестры, ведомости | Одна строка шапки из заголовков колонок |
**Форматный макет** | Печатные бланки: счёт-фактура, накладная | Уровни шапки, объединения, поворот текста |

**Выбор сохраняется в макете** — в поле `LayoutKind` листа. Открыв отчёт
позже, вы увидите тот же вид.

**Что меняется при выборе:**

| Вид | Панель «Уровни шапки» |
| --- | --- |
Простой | Скрыта |
Форматный | **Показана** |

## 3. Многоуровневая шапка

Открывается в блоке **«Таблица»**, раздел **«Уровни шапки (для форматного макета)»**.

### Как это работает

Шапка бланка — это сетка. Ячейка задаётся четырьмя числами:

| Что | Значение |
| --- | --- |
**Уровень** | 0 — верхний, 1 — ниже, и так далее |
**Колонка** | С какой колонки начинается |
**До кол.** | По какую колонку включительно |
**RowSpan** | Сколько уровней занимает по вертикали |

### Пример: шапка счёта-фактуры

| Уровень | Колонка | До кол. | RowSpan | Подпись | Поворот |
| --- | --- | --- | --- | --- | --- |
0 | 1 | 2 | **2** | Сведения о товарах | 0 |
0 | 3 | 4 | 1 | Количество | 90 |
0 | 5 | 6 | 1 | Стоимость | 90 |
0 | 7 | 7 | **2** | НДС | 90 |
0 | 8 | 8 | **2** | Сумма НДС | 90 |
0 | 9 | 9 | **2** | Всего | 90 |
1 | 3 | 3 | 1 | Ед. изм. | 90 |
1 | 4 | 4 | 1 | Кол-во | 90 |
1 | 5 | 5 | 1 | Цена | 90 |
1 | 6 | 6 | 1 | Без налога | 90 |

**Что получится:**

```
┌──────────────────────┬─────────────┬─────────────┬──────┬───────────┬───────┐
│                      │ Количество  │ Стоимость   │      │ Сумма НДС │ Всего │
│ Сведения о товарах   │   ↕         │   ↕         │ НДС  │    ↕      │  ↕    │
│                      ├──────┬──────┼──────┬──────┤  ↕   │           │       │
│                      │Ед.изм│Кол-во│ Цена │Без н.│      │           │       │
├──────────────────────┼──────┼──────┼──────┼──────┼──────┼───────────┼───────┤
│ 1  Услуги            │ кВт.ч│ 1,00 │2000,66│2000,66│ 12,00│   240,08  │2240,74│
└──────────────────────┴──────┴──────┴──────┴──────┴──────┴───────────┴───────┘
```

### Правила

| Правило | Почему |
| --- | --- |
**Пустая подпись в нижнем уровне** | Подставится заголовок колонки |
**`RowSpan = 1`** | Ячейка занимает только свой уровень |
**`RowSpan = 2`** | Ячейка занимает свой уровень и следующий |
**Ячейки не должны пересекаться** | Перекрытая ячейка пропускается |
**Пустой список уровней** | Шапка из одной строки — по заголовкам колонок |

### Высота строки шапки

Поле **«Высота строки шапки»** — в пунктах. Задаёт высоту каждой строки
шапки. Для вертикальных подписей нужна высокая строка: **80–100 пт**.

---

## 4. Поворот текста

Задаётся в трёх местах:

| Где | Поле | Для чего |
| --- | --- | --- |
Вкладка «Общие» → ячейки | **Поворот** | Текст в заголовке или свободной строке |
Блок «Таблица» → колонки | **Поворот** | Подпись колонки в простой шапке |
Блок «Таблица» → уровни шапки | **Поворот** | Подпись графы в форматной шапке |

**Допустимые значения:**

| Значение | Как встанет текст |
| --- | --- |
**0** | Обычно, слева направо |
| **90** | Снизу вверх |
| **270** | Сверху вниз |
| **45** | По диагонали |

Для бланка со графами применяется **90** — подпись читается снизу вверх,
как в форме СТ-1.

## 5. Что добавлено в модель

Файл `Models/ClosedXmlReportLayout.cs`.

### Вид макета

```csharp
public static class ClosedXmlLayoutKinds
{
    public const string Simple = "Simple";        // таблица с одной строкой шапки
    public const string Formatted = "Formatted";  // бланк с многоуровневой шапкой
}
```

Поле листа:

```csharp
public string LayoutKind { get; set; } = ClosedXmlLayoutKinds.Simple;
```

### Поворот и перенос

Ячейка текста (`ClosedXmlTextCell`):

```csharp
/// <summary>Поворот текста в градусах: 0, 45, 90, 270.</summary>
public int TextRotation { get; set; }

/// <summary>Перенос текста по словам.</summary>
public bool WrapText { get; set; }
```

Колонка таблицы (`ClosedXmlColumn`):

```csharp
/// <summary>Поворот подписи колонки; нужен для бланков.</summary>
public int TextRotation { get; set; }
```

### Уровни шапки

```csharp
public class ClosedXmlHeaderLevel
{
    public string Name { get; set; }
    public List<ClosedXmlHeaderCell> Cells { get; set; }
}

public class ClosedXmlHeaderCell
{
    public int Column { get; set; }         // с какой колонки
    public int MergeToColumn { get; set; }  // по какую включительно
    public int RowSpan { get; set; } = 1;   // сколько уровней занимает
    public string Text { get; set; }        // пусто в нижнем уровне — из колонки
    public bool Bold { get; set; } = true;
    public string Align { get; set; } = "Center";
    public int TextRotation { get; set; }
    public string Fill { get; set; }
}
```

Секция таблицы:

```csharp
/// <summary>Уровни шапки сверху вниз. Пусто — шапка из одной строки.</summary>
public List<ClosedXmlHeaderLevel> HeaderLevels { get; set; } = new();

/// <summary>Высота строки шапки в пунктах.</summary>
public double HeaderRowHeight { get; set; }
```

## 6. Вывод

### Excel

**Многоуровневая шапка** — метод `WriteMultiLevelHeader`:

- уровни идут сверху вниз;
- объединение по колонкам: `worksheet.Range(row, from, row, to).Merge()`;
- объединение по уровням: `worksheet.Range(row, from, lastRow, to).Merge()`;
- поворот: `cell.Style.Alignment.TextRotation`;
- высота строки: `worksheet.Row(rowIndex).Height`.

**Занятые ячейки** отслеживаются набором `(уровень, колонка)`:
объединение по уровням перекрывает те же колонки на нижних уровнях,
и повторная запись в них недопустима.

### PDF

**Многоуровневая шапка** — метод `RenderMultiLevelHeader`:

- `cell.ColumnSpan(n)` — объединение по колонкам;
- `cell.RowSpan(n)` — объединение по уровням;
- пустая подпись нижнего уровня заменяется заголовком колонки.

**Поворот текста.** В PDF поворота текста нет, поэтому подпись рисуется
средствами WPF в картинку и вставляется в документ:

```csharp
var visual = new DrawingVisual();
using (var context = visual.RenderOpen())
{
    context.PushTransform(new RotateTransform(angle, imageWidth / 2d, imageHeight / 2d));
    context.DrawText(formatted, new Point(...));
    context.Pop();
}
```

| Решение | Зачем |
| --- | --- |
**Кэш картинок** | Одинаковые подписи рисуются один раз |
**Ограничение высоты** | Высокая картинка растянула бы строку шапки |
**Шрифт листа** | Подпись набрана тем же шрифтом, что и документ |
| **Запасной путь** | Если картинку собрать не удалось — текст выводится как есть |

## 7. Конструктор

### Что добавлено

| Место | Что |
| --- | --- |
Вкладка «Общие» | Переключатель **Простой / Форматный макет** |
Вкладка «Общие» → ячейки | Колонки **Поворот** и **Перенос** |
Блок «Таблица» → колонки | Колонка **Поворот** |
Блок «Таблица» | Раздел **«Уровни шапки»** с таблицей ячеек |
Блок «Таблица» | Поле **«Высота строки шапки»** |

### Как задать уровни

1. Вкладка **📋 Общие** → выбрать **Форматный макет**.
2. Вкладка **📊 ClosedXML макет** → блок **Таблица**.
3. Развернуть **«Уровни шапки (для форматного макета)»**.
4. Заполнить таблицу: уровень, колонка, до кол., подпись, поворот.
5. Задать **«Высота строки шапки»** — например 90.
6. Нажать **📄 Предпросмотр PDF**.

**Уровень 0 — верхний.** Пустая подпись в последнем уровне подставит
заголовок колонки.

## 9. Ограничения

| Ограничение | Состояние |
| --- | --- |
**В PDF вертикальная подпись — картинка** | Крупнее, чем в Excel: векторного поворота в PDF нет |
**Размер подписи в PDF** | Ограничен высотой строки шапки |
**Длинная подпись при 90°** | Уменьшается, чтобы влезть в строку |
**Поворот 270°** | Приводится к 90°: читаемость сохраняется |
**Строка шапки в PDF** | Высота определяется содержимым, настройка влияет только на Excel |

**Excel передаёт бланк точно.** PDF подходит для просмотра и печати,
но вертикальные подписи в нём крупнее.

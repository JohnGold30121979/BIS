# Абонентский отдел: справочники участков, льгот, улиц и лицевых счетов

Документ по доработке модуля **«Абонентский отдел»**: добавлены справочники
«Участки абонентского отдела», «Льготы», «Улицы» и «Лицевые счета», а также
форма ввода лицевого счёта (стандартная карточка справочника).

Дата: 30.10.2026. Сборка: `1.1.799`.

---

## 1. Что создано

| Справочник | Таблица | Поля (тип) |
|---|---|---|
| Участки абонентского отдела | `catalog_abonent_sites` | Номер (String, уникальный), Участок (String), Активен (Bool) |
| Льготы | `catalog_benefits` | Номер (String, уникальный), Льгота (String), Процент (Decimal 18,2), Активен (Bool) |
| Улицы | `catalog_streets` | Номер (String, уникальный), Улица (String), Активен (Bool) |
| Лицевые счета | `catalog_personal_accounts` | Лицевой счет (String, уникальный), Участок (Reference), Улица (Reference), Дом (String), Кв (String), Льгота (Reference), Площадь (Decimal 18,3), Объем (Decimal 18,3), Активен (Bool) |

Ссылки в «Лицевых счетах»:

- **Участок** → `Участки абонентского отдела`, отображение `{Номер} - {Участок}`;
- **Улица** → `Улицы`, отображение `{Номер} - {Улица}`;
- **Льгота** → `Льготы`, отображение `{Номер} - {Льгота}`.

Все четыре справочника — системные (`IsSystem = true`) и привязаны к модулю
**«Абонентский отдел»**, поэтому появляются в навигации этого модуля.

> Имя «Участки абонентского отдела» выбрано специально: имя «Участки» уже занято
> общим справочником участков предприятия (`catalog_sites`), на который ссылаются
> документы и аналитика счетов. Второй справочник с тем же именем сломал бы
> ссылки `ReferenceCatalog = "Участки"`.

### 2.2. Создание справочников — `Services/MetadataService.Catalogs.cs`

Общий помощник создаёт системный справочник с полями, сохраняет метаданные
и создаёт таблицу:

```csharp
private async Task CreateAbonentCatalog(
    MetadataConfiguration config,
    string name,
    string tableName,
    string icon,
    string description,
    int order,
    Func<Guid, List<MetadataField>> fieldsFactory)
{
    try
    {
        var catalog = new MetadataObject
        {
            Id = Guid.NewGuid(),
            Name = name,
            TableName = tableName,
            ObjectType = "Catalog",
            Description = description,
            Icon = icon,
            Order = order,
            IsSystem = true,
            MetadataConfigId = config.Id,
            Fields = fieldsFactory(Guid.NewGuid())
        };
        await _context.MetadataObjects.AddAsync(catalog);
        await _context.SaveChangesAsync();
        await CreateTableForCatalogAsync(catalog);
    }
    catch (Exception ex)
    {
        System.Diagnostics.Debug.WriteLine($"Ошибка создания справочника '{name}': {ex.Message}");
    }
}
```

Догоняющий шаг для уже созданных баз добавляет недостающие поля и колонки:

```csharp
private async Task EnsureAbonentCatalogStructureAsync(
    string catalogName,
    string tableName,
    Func<Guid, List<MetadataField>> fieldsFactory)
{
    var catalog = await _context.MetadataObjects
        .Include(metadata => metadata.Fields)
        .FirstOrDefaultAsync(metadata =>
            metadata.ObjectType == "Catalog" &&
            (metadata.Name == catalogName || metadata.TableName == tableName));
    if (catalog == null)
        return;

    await CreateTableForCatalogAsync(catalog);

    var existingByColumn = catalog.Fields
        .Where(field => !string.IsNullOrWhiteSpace(field.DbColumnName))
        .GroupBy(field => field.DbColumnName, StringComparer.OrdinalIgnoreCase)
        .ToDictionary(group => group.Key, group => group.First(), StringComparer.OrdinalIgnoreCase);

    foreach (var desired in fieldsFactory(catalog.Id))
    {
        if (!existingByColumn.TryGetValue(desired.DbColumnName, out var existing))
        {
            desired.Id = Guid.NewGuid();
            desired.MetadataObjectId = catalog.Id;
            await _context.MetadataFields.AddAsync(desired);
            await AddColumnToTableAsync(catalog.TableName, desired);
            catalog.Fields.Add(desired);
            continue;
        }

        existing.Name = desired.Name;
        existing.FieldType = desired.FieldType;
        existing.Length = desired.Length;
        existing.Precision = desired.Precision;
        existing.Scale = desired.Scale;
        existing.IsRequired = desired.IsRequired;
        existing.IsUnique = desired.IsUnique;
        existing.Order = desired.Order;
        existing.ReferenceCatalog = desired.ReferenceCatalog;
        existing.DisplayPattern = desired.DisplayPattern;
        existing.DisplayFields = desired.DisplayFields;
    }

    await _context.SaveChangesAsync();
}
```

### 2.3. Запуск при старте — `Services/MetadataService.cs`

В `InitializePredefinedCatalogsAsync` после справочников производственных
участков:

```csharp
if (!existingCatalogs.Contains("Участки абонентского отдела"))
    await CreateAbonentSitesCatalog(config);
await EnsureAbonentSitesCatalogStructureAsync();

if (!existingCatalogs.Contains("Льготы"))
    await CreateBenefitsCatalog(config);
await EnsureBenefitsCatalogStructureAsync();

if (!existingCatalogs.Contains("Улицы"))
    await CreateStreetsCatalog(config);
await EnsureStreetsCatalogStructureAsync();

if (!existingCatalogs.Contains("Лицевые счета"))
    await CreatePersonalAccountsCatalog(config);
await EnsurePersonalAccountsCatalogStructureAsync();
```

Порядок важен: участки, льготы и улицы создаются раньше лицевых счетов —
на них ссылаются поля лицевого счёта.

## 3. Форма ввода

Форма — стандартная карточка справочника «Лицевые счета»:

1. «Абонентский отдел» → «Лицевые счета» → «Добавить» (или двойной клик по записи).
2. Поля идут в порядке `Order`:
   **Лицевой счет → Участок → Улица → Дом → Кв → Льгота → Площадь → Объем → Активен**.
3. «Участок», «Улица», «Льгота» — выпадающие списки с поиском; отображаются
   как «номер — наименование» (например, «1 — Московский уч.»).
4. «Лицевой счет» обязателен и уникален; остальные реквизиты можно заполнить позже.

Форма строится общим механизмом `CatalogItemDialog` по метаданным, поэтому
никаких отдельных WPF-окон для этих справочников не требуется: поля, типы
и справочники-источники берутся из `MetadataField`.

# Отчёт по документу своими руками: инструкция администратора

Инструкция для администратора, который **знает SQL** и хочет сделать отчёт
по документу без программиста и без пересборки программы.

Разобрано на живом примере: **журнал счет-фактур**. Этот отчёт уже сделан
и лежит в базе как образец — его можно открыть, посмотреть запрос и править
под свою форму.

---

## Что нужно знать в самом начале

**Вам не нужен программист.** Отчёт состоит из двух частей:

| Часть | Кто делает | Где |
| --- | --- | --- |
**Данные** — SQL-запрос | **Вы** | Экран «Наборы данных» |
**Вид** — макет | **Вы** | Конструктор, вкладка «ClosedXML макет» |

**Программа не пересобирается.** Всё делается в работающей системе.

---

## Шаг 1. Найти таблицы документа

Каждый документ хранится в двух таблицах:

| Таблица | Что внутри |
| --- | --- |
`doc_имя_документа` | **Шапка**: номер, дата, организация, суммы, статус |
`doc_имя_документа_lines` | **Строки**: товары, услуги, количество, цены |

**Пример — счета-фактуры:**

| Таблица | Что |
| --- | --- |
`doc_sales_invoice` | Выданные счета-фактуры (шапка) |
`doc_sales_invoice_lines` | Строки выданных счет-фактур |
`doc_purchase_invoice` | Полученные счета-фактуры (шапка) |
`doc_purchase_invoice_lines` | Строки полученных |

### Как узнать имена колонок

**Способ 1 — через конфигуратор:** откройте документ, посмотрите поля.

**Способ 2 — запросом.** Создайте набор данных с таким запросом и нажмите «Тест»:

```sql
SELECT column_name, data_type
FROM information_schema.columns
WHERE table_schema = 'public'
  AND table_name = 'doc_sales_invoice'
ORDER BY ordinal_position
```

**Способ 3 — посмотреть образец.** Откройте набор данных
**«Счет-фактуры выданные и полученные»** — там готовый запрос по двум документам.

### Важные правила по таблицам

| Что | Как |
| --- | --- |
Имена таблиц и колонок | **Строчные**, через подчёркивание |
В SQL их берут **в двойные кавычки** | `""doc_number""` — так требует PostgreSQL |
Названия на русском | Только в комментариях и подписях, не в именах |

## Шаг 2. Написать запрос

### Правило первое: только чтение

Разрешены **только** `SELECT` и `WITH`. Изменения данных запрещены —
система не даст сохранить такой запрос.

### Правило второе: параметры

В запросе можно использовать готовые параметры:

| Параметр | Что подставится |
| --- | --- |
`@PeriodStart` | Начало периода |
`@PeriodEnd` | Конец периода |
`@OrganizationId` | Организация (пустая строка = все) |
`@CashDeskId` | Касса |
`@EmployeeId` | Сотрудник |
`@AccountCode` | Счёт |
`@UserName` | Логин пользователя |

**Важно:** если пустой период не задан, подставляется **текущий месяц**.
Поэтому при проверке старого документа задавайте период явно.

### Правило третье: список параметров закрыт

**Свои параметры придумывать нельзя.** Если написать `@MyParam`, запрос
не выполнится: система создаёт только параметры из таблицы выше.

### Правило четвёртое: типы приводите явно

PostgreSQL строгий. Если сравниваете с пустой строкой — приводите тип:

```sql
AND (CAST(@OrganizationId AS text) = '' OR organization_id = CAST(@OrganizationId AS text))
```

### Правило пятое: NULL заменяйте

Пустое значение ломает отчёт. Используйте `COALESCE`:

```sql
COALESCE(i.""esf_number"", '')    AS esf_number,
COALESCE(i.""amount"", 0)         AS total_amount
```

## Шаг 3. Разобрать готовый запрос

Откройте набор данных **«Счет-фактуры выданные и полученные»**.
Вот его запрос с пояснениями:

```sql
WITH invoice_rows AS (
    SELECT
        i.""doc_number""                              AS doc_number,
        i.""doc_date""::date                          AS doc_date,
        COALESCE(i.""organization_id""::text, '')     AS organization_id,
        COALESCE(o.""name"", '')                      AS org_name,
        COALESCE(NULLIF(i.""esf_number"", ''), '')    AS esf_number,
        COALESCE(i.""amount_without_tax"", 0)         AS amount_without_tax,
        COALESCE(i.""vat_total"", 0)                  AS vat_total,
        COALESCE(i.""sales_tax_total"", 0)            AS sales_tax_total,
        COALESCE(i.""amount"", 0)                     AS total_amount,
        CASE WHEN COALESCE(i.""is_posted"", false)
             THEN 'Проведён' ELSE 'Не проведён' END   AS posted_state,
        'Выписка'                                     AS document_kind
    FROM ""doc_sales_invoice"" i
    LEFT JOIN catalog_organizations o
           ON i.""organization_id""::text = o.""Id""::text

    UNION ALL

    SELECT
        p.""doc_number"",
        p.""doc_date""::date,
        COALESCE(p.""organization_id""::text, ''),
        COALESCE(o.""name"", ''),
        ...                                           -- те же колонки
    FROM ""doc_purchase_invoice"" p
    LEFT JOIN catalog_organizations o
           ON p.""organization_id""::text = o.""Id""::text
)
SELECT
    doc_number,
    doc_date,
    org_name,
    'Журнал за период ' || TO_CHAR(CAST(@PeriodStart AS date), 'DD.MM.YYYY')
                        || ' - ' || TO_CHAR(CAST(@PeriodEnd AS date), 'DD.MM.YYYY')
                                                      AS report_title,
    TO_CHAR(CAST(@PeriodStart AS date), 'DD.MM.YYYY') AS period_start,
    TO_CHAR(CAST(@PeriodEnd AS date), 'DD.MM.YYYY')   AS period_end
FROM invoice_rows
WHERE doc_date >= CAST(@PeriodStart AS date)
  AND doc_date <= CAST(@PeriodEnd AS date)
  AND (CAST(@OrganizationId AS text) = '' OR organization_id = CAST(@OrganizationId AS text))
ORDER BY doc_date DESC, doc_number DESC
```

### Что здесь применено

| Приём | Зачем |
| --- | --- |
`WITH ... AS (...)` | Временный набор: сначала готовим строки, потом отбираем |
`UNION ALL` | Соединить выданные и полученные в один список |
`LEFT JOIN catalog_organizations` | Подставить название организации |
`COALESCE(..., '')` | Убрать `NULL` из текста |
`COALESCE(..., 0)` | Убрать `NULL` из сумм |
`NULLIF(x, '')` | Пустую строку превратить в `NULL` |
`i.""doc_date""::date` | Убрать время, оставить дату |
`i.""organization_id""::text` | Привести `uuid` к тексту для сравнения |
`CASE WHEN ... THEN ... END` | Получить читаемый текст вместо кода |
`TO_CHAR(дата, 'DD.MM.YYYY')` | Дата в привычном виде |
`\|\|` | Склеить строки |

### Три колонки, которые нужны всегда

Их читает макет, чтобы вывести шапку отчёта:

| Колонка | Что в ней |
| --- | --- |
**`report_title`** | Заголовок отчёта |
**`period_start`** | Начало периода |
**`period_end`** | Конец периода |

Если их не заполнить, шапка отчёта выйдет пустой.

## Шаг 4. Проверить и сохранить

| Действие | Что происходит |
| --- | --- |
Кнопка **Тест** | Показывает таблицу результата. Так проверяется запрос |
Кнопка **Сохранить** | Запоминает набор и **создаёт источник данных** |

**После сохранения система сама создаёт:**

1. **источник данных** с именем набора;
2. **колонки** — из вашего запроса.

**Проверка:** в списке полей набора должны появиться все ваши колонки.
Если список пуст — запрос не выполнился, смотрите ошибку.

## Шаг 6. Собрать вид

Вкладка **📊 ClosedXML макет**.

### Три блока в норме

| Блок | Что в нём |
| --- | --- |
**Заголовок** (`TitleRows`) | Заголовок отчёта и период |
**Таблица** (`TabularSection`) | Колонки отчёта |
**Подписи** (`SignaturesRow`) | Если нужны |

### Настройка шапки

| Поле | Что писать |
| --- | --- |
Column | Номер колонки: 1 |
MergeToColumn | До какой колонки объединить: например 10 |
TakeFromRow | **1** — взять из первой строки данных |
TakeFromField | `report_title` — имя колонки из запроса |
Bold | Поставить галочку |
Align | `Center` |

**Для периода:** второй блок, `TakeFromRow = 2`, `TakeFromField = period_start`.

### Настройка таблицы

Для каждой колонки:

| Поле | Что писать | Пример |
| --- | --- | --- |
Field | **Имя колонки из запроса** | `total_amount` |
Header | **Подпись на бумаге** | Всего |
Width | Ширина | 15 |
Align | `Left`, `Center`, `Right` | Right |
NumberFormat | Формат числа | `#,##0.00` |
SuppressZero | Не печатать нули | галочка |

### Важно: пропуск строк

Заголовок и период попадают в строки набора. Чтобы они **не повторялись
в таблице**, заполните:

| Поле | Значение |
| --- | --- |
SkipRowsStartingWith | `Оборотно-сальдовая`, `Период` |
SkipEmptyRows | галочка |

### Проверка вида

Кнопки на вкладке:

| Кнопка | Что делает |
| --- | --- |
**📊 Предпросмотр Excel** | Открывает Excel |
**📄 Предпросмотр PDF** | Открывает PDF внутри программы |

**Макет правится без пересборки** — сохранили, и он сразу в базе.

## Частые ошибки и что делать

| Ошибка | Причина | Решение |
| --- | --- | --- |
**столбец "xxx" не существует** | Опечатка в имени колонки | Сверить с таблицей |
**оператор не существует: text = uuid** | Сравнение разных типов | `CAST(... AS text)` |
**разрешены только SELECT/WITH** | Запрос начинается с другого слова | Начать с `SELECT` |
**содержит запрещённую команду** | Есть `DELETE`, `UPDATE`, `DO` и подобное | Только чтение |
**колонки не появились** | Запрос не выполнился | Нажать «Тест», прочитать ошибку |
**колонка пустая в отчёте** | Имя в макете не совпадает | Сверить `Field` и колонку запроса |
**заголовок в теле таблицы** | Строка не пропущена | `SkipRowsStartingWith` |
**суммы пустые** | `NULL` в данных | `COALESCE(сумма, 0)` |
**мало строк** | Период по умолчанию — текущий месяц | Задать период явно |
**весь текст в одну строку** | Перенос строк в макете | Разбить на блоки |

## Полезные приёмы SQL

### Соединить шапку и строки

```sql
SELECT i.""doc_number"", l.""line_number"", l.""name"", l.""quantity"", l.""line_total""
FROM ""doc_sales_invoice"" i
JOIN ""doc_sales_invoice_lines"" l ON l.""invoice_id"" = i.""Id""
WHERE i.""doc_date""::date >= CAST(@PeriodStart AS date)
```

**Строк будет столько, сколько позиций в документах.**

### Подставить название организации

```sql
LEFT JOIN catalog_organizations o ON i.""organization_id""::text = o.""Id""::text
```

### Читаемый текст вместо кода

```sql
CASE WHEN COALESCE(i.""is_posted"", false)
     THEN 'Проведён' ELSE 'Не проведён' END AS posted_state
```

### Строка «ИТОГО»

```sql
UNION ALL
SELECT 'ИТОГО', '', '', SUM(amount_without_tax), SUM(vat_total), SUM(amount)
FROM отобранные_строки
```

Затем в макете добавьте правило выделения:
`Match = StartsWith`, `Text = ИТОГО`, `Bold = галочка`.

### Дата в привычном виде

```sql
TO_CHAR(док.""doc_date"", 'DD.MM.YYYY')  AS doc_date_text
```

## Что важно помнить

1. **Две таблицы на документ**: шапка и строки.
2. **Имена в двойных кавычках**, иначе PostgreSQL не поймёт регистр.
3. **Только `SELECT`/`WITH`** — изменения запрещены.
4. **Параметры — из закрытого списка**, свои не работают.
5. **`report_title`, `period_start`, `period_end`** — для шапки отчёта.
6. **Типы приводите явно**, `NULL` заменяйте через `COALESCE`.
7. **Период по умолчанию — текущий месяц**, при проверке задавайте явно.
8. **`Field` в макете = имя колонки запроса.** Это единственная связь.
9. **Макет правится без пересборки.**
10. **Начните с копии образца** — так быстрее и без ошибок.
